# Créditos de imágenes

Sitio de demostración de un negocio ficticio (Papel Vegetal, estudio de tatuaje).

## No hay ninguna fotografía

Esta plantilla **no usa fotografías**: ni de tatuajes, ni de personas, ni de locales.
Es una decisión de contenido, no una limitación. Enseñar tatuajes reales en la web de
un estudio ficticio obligaría a usar obra de tatuadores identificables, y eso no se
hace aquí.

## Ilustraciones — propias

Todo lo que se ve está dibujado en SVG para esta plantilla, sin generador de imágenes:

| Archivo | Qué es |
|---|---|
| `assets/flash/golondrina.svg` | Golondrina con el ala abierta |
| `assets/flash/punal.svg` | Puñal atravesando una rosa |
| `assets/flash/serpe.svg` | Serpiente en ese con la lengua fuera |
| `assets/flash/lua.svg` | Luna creciente con un ojo |
| `assets/flash/vela.svg` | Vela encendida en su palmatoria |
| `assets/flash/ancora.svg` | Ancla con cuerda |
| `assets/flash/polilla.svg` | Polilla simétrica |
| `assets/flash/fento.svg` | Hoja de helecho con el cayado |
| `assets/flash/faro.svg` | Faro sobre el mar |
| `assets/flash/corazon.svg` | Corazón cruzado por una cinta |
| `favicon.svg` | La «P» del estudio con un punto de tinta |
| `assets/og.png` | Imagen para compartir, 1200×630, compuesta con los mismos elementos |

Cada dibujo tiene dos capas: `.trazo` (la línea, que se dibuja sola con
`stroke-dasharray`) y `.tinta` (las manchas violeta, que aparecen al entintar). Los
SVG están además en línea dentro de `index.html`, que es lo que permite animarlos; los
archivos de `assets/flash/` son la fuente y se usan para generar la imagen de compartir.
